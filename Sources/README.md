# Catalogue de sources — MonCloudstream

Ce dossier centralise les sites et leurs URL. Les entrées sont des liens vers les sites officiels ; ce catalogue ne récupère pas automatiquement les vidéos et n'est pas encore affiché comme une page dans l'interface CloudStream.

## Ajouter une source

Ajoute une entrée dans `sources.json` avec un identifiant, un nom, une URL HTTPS et une courte description. Privilégie les sites officiels, les contenus du domaine public et les sources que tu es autorisé à intégrer.
